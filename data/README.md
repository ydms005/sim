# data/ — 사이트 데이터 원본 (CSV)

이 폴더의 CSV 파일이 사이트에 보이는 모든 데이터의 **원본**입니다.
`npm run dev`·`npm run build` 를 실행하면 `scripts/build-data.mjs` 가 먼저 돌면서 CSV를 검사하고
`public/data/*.json` 을 새로 만듭니다. `public/data/` 는 자동 생성물이라 Git에 올리지 않습니다.

> **1단계(현재)**: 대학 목록은 실제 대학 기준이지만, 경쟁률·모집요강·자료실·소식은 모두 **개발용 샘플**입니다.
> **2단계(예정)**: 관리자가 엑셀 파일을 올려 이 CSV들을 갱신하는 기능을 추가할 예정입니다. 열 이름과 검사 규칙은 그대로 유지됩니다.

```
data/universities.csv ─┐
data/competition.csv  ─┤                          ┌─ public/data/universities.json
data/guidelines.csv   ─┼─ scripts/build-data.mjs ─┼─ public/data/univ/{대학ID}.json
data/resources.csv    ─┤     (검사 → 변환)          └─ public/data/trends.json
data/news.csv         ─┘
public/files/univ/{대학ID}/*.pdf  ← guidelines.csv·resources.csv 가 가리키는 PDF (Git에 포함)
```

## 파일과 열

모든 파일은 **UTF-8 CSV**, 첫 줄은 아래의 한글 열 이름입니다. 값에 쉼표·줄바꿈·큰따옴표가 있으면 값 전체를 `"…"` 로 감싸고,
값 안의 큰따옴표는 `""` 로 두 번 적습니다. 예: `"인용"으로 시작` → `"""인용""으로 시작"`, `서울, 경기` → `"서울, 경기"`.
열 순서는 바뀌어도 되지만 열 이름은 정확히 같아야 합니다. 모르는 열은 경고만 하고 무시합니다.

**큰따옴표 짝 검사** — 짝이 맞지 않는 따옴표가 하나 있으면 그 뒤의 여러 행이 값 하나로 합쳐져 조용히 사라질 수 있으므로 엄격하게 검사합니다.
- `"…"` 로 감싼 값의 닫는 따옴표 뒤에는 공백과 쉼표·줄바꿈만 올 수 있습니다. `"인용"으로 시작` 처럼 뒤에 글자가 이어지면 오류입니다.
  앞 행에서 연 따옴표가 뒤 행에서 닫혔다면 `[… 5행] 2행에서 시작한 큰따옴표 값이 5행에서 닫혔는데 …` 처럼 두 줄 번호를 모두 알려 줍니다.
- 파일 끝까지 닫히지 않은 따옴표는 오류입니다.
- 줄바꿈은 **news.csv 의 `요약`, resources.csv 의 `부제`** 에만 쓸 수 있습니다. 다른 열(대학ID·대학명·학년도·모집단위·전형명·숫자·날짜·제목·파일·링크 등)에
  줄바꿈이 있으면 따옴표 짝이 맞지 않아 여러 행이 합쳐진 것으로 보고 오류로 알립니다.
- `요약`·`부제` 가 여러 줄인데 그 안에 `3,2026-09-08,…` 처럼 CSV 행으로 보이는 줄이 있으면 경고합니다(빌드는 계속되므로 경고를 꼭 확인하세요).

### universities.csv — 대학 목록 (필수)

| 열 | 설명 | 예 |
|---|---|---|
| 대학ID | 1 이상의 정수. **한 번 정하면 바꾸거나 재사용하지 않습니다**(주소 `/univ/3` 이 이 값입니다). | `3` |
| 대학명 | 공식 교명 | `건국대학교` |
| 지역 | `서울 경기 인천 부산 대구 광주 대전 울산 세종 강원 충북 충남 전북 전남 경북 경남 제주` 중 하나 | `서울` |
| 설립구분 | `국립` · `공립` · `사립` 중 하나 | `사립` |
| 캠퍼스 | 같은 이름의 대학이 여러 행일 때 구분용. 없으면 비움 | `서울캠퍼스` |
| 홈페이지 | 대학 대표 홈페이지(`https://…`). 확실하지 않으면 비움 | `https://www.konkuk.ac.kr` |

- `대학명+캠퍼스` 조합은 중복될 수 없습니다.
- 사이트에서는 대학명 가나다순으로 보여 줍니다(같은 이름이면 대학ID 순).

### competition.csv — 수시 경쟁률

| 열 | 설명 | 예 |
|---|---|---|
| 대학ID | universities.csv 에 있는 ID | `3` |
| 학년도 | 입학 학년도(4자리) | `2026` |
| 모집단위 | 학과·학부 이름 | `경영학과` |
| 전형명 | 전형 전체 이름 | `학생부종합(KU자기추천)` |
| 전형유형 | `학생부종합` · `학생부교과` · `논술` · `실기/실적` 중 하나 | `학생부종합` |
| 모집인원 | 0 이상의 정수(천 단위 쉼표 허용) | `16` |
| 지원자수 | 0 이상의 정수 | `258` |

- `대학ID+학년도+모집단위+전형명` 은 한 번만 나올 수 있습니다.
- 같은 대학·학년도에서 같은 전형명은 전형유형이 같아야 합니다.
- 경쟁률 행이 하나라도 있는 대학은 목록에서 `hasData: true` 가 됩니다(아래 [hasData 와 hasDetail](#hasdata-와-hasdetail) 참고).
- `trends.json`(경쟁률 추세)은 대학·학년도별로 모든 행의 모집인원·지원자수를 더한 값입니다.

### guidelines.csv — 모집요강 PDF

| 열 | 설명 | 예 |
|---|---|---|
| 대학ID | | `3` |
| 학년도 | 대학·학년도마다 1개. 화면에는 `2027학년도 수시` 로 표시 | `2027` |
| 제목 | PDF 뷰어 위쪽에 표시되는 제목 | `2027학년도 수시모집요강 (샘플)` |
| 파일 | `public/` 기준 경로(반드시 `.pdf`, 실제 파일이 있어야 함) 또는 `https://` 주소 | `files/univ/3/guideline-2027.pdf` |

### resources.csv — 자료실

| 열 | 설명 | 예 |
|---|---|---|
| 대학ID | | `3` |
| 분류 | `대입자료` · `면접자료` 중 하나 | `면접자료` |
| 제목 | 파일 목록에 크게 보이는 제목 | `[건국대] 면접 기출 예시 문항` |
| 부제 | 제목 아래 작은 글씨(선택). 줄바꿈을 넣어도 되지만(값 전체를 `"…"` 로 감쌈) 화면에서는 한 줄로 이어 보입니다 | `학생부종합 · 서류 기반 면접` |
| 파일 | guidelines.csv 와 같은 규칙 | `files/univ/3/res-interview-questions.pdf` |

- 화면의 파일 순서는 CSV에 적은 순서를 따릅니다. `대학ID+분류+제목` 은 중복될 수 없습니다.

### news.csv — 대학 소식

| 열 | 설명 | 예 |
|---|---|---|
| 대학ID | | `3` |
| 날짜 | `YYYY-MM-DD` | `2026-09-09` |
| 제목 | | `2027학년도 수시모집 원서접수 안내` |
| 요약 | 한두 문장. 줄바꿈을 넣으면(값 전체를 `"…"` 로 감쌈) 화면에서도 그 자리에서 줄이 바뀝니다 | |
| 링크 | 원문 주소(선택, `https://…`) | |

- 최신 날짜가 위로 오도록 자동 정렬됩니다.

## 이렇게 추가하세요

**대학 추가** — universities.csv 맨 아래에 새 행을 붙이고, 지금까지 쓴 가장 큰 대학ID + 1 을 줍니다. 폐교·통합된 대학도 ID를 다른 대학에 다시 쓰지 않습니다(행을 지우면 그 ID는 비워 둡니다).

**경쟁률 추가** — competition.csv 에 `대학ID,학년도,모집단위,전형명,전형유형,모집인원,지원자수` 행을 붙입니다. 순서는 상관없습니다.

**PDF 추가** — PDF를 `public/files/univ/{대학ID}/` 에 넣고(파일 이름은 영문·숫자·`-` 권장), guidelines.csv 또는 resources.csv 에 `files/univ/{대학ID}/파일이름.pdf` 로 적습니다.
- 파일·폴더 이름에 **`#` `?` `%` 는 쓸 수 없습니다**(검사 오류). 경로가 그대로 웹 주소가 되는데, `#`·`?` 뒤는 주소에서 잘려 나가고 `%` 는 인코딩 표시로 해석되어
  검사를 통과해도 사이트에서 PDF가 열리지 않기 때문입니다. 한글·공백·괄호는 써도 됩니다(예: `2027 수시 모집요강 (최종).pdf`).
- CSV의 경로는 **대소문자까지** 실제 파일과 같아야 합니다. Windows·macOS 에서는 `Guideline.pdf` 로 적어도 `guideline.pdf` 가 열리지만,
  GitHub Pages 는 대소문자를 구분해 찾지 못하므로 검사에서 오류로 알려 줍니다.
- 맨 앞의 `public/`·`/`, 역슬래시(`\`), `//` 는 알아서 정리합니다. `..` 는 쓸 수 없습니다.

경쟁률이 아직 없는 대학이어도 됩니다. 모집요강·자료실·소식 중 하나라도 있으면 그 대학의 상세 파일이 만들어져 해당 탭에 바로 보입니다(`hasDetail`).
외부에 있는 PDF는 `https://` 주소를 그대로 적어도 됩니다. 다만
- `http://` 주소는 오류입니다. 사이트가 HTTPS(GitHub Pages)라서 브라우저가 혼합 콘텐츠로 막아 뷰어에서 열 수 없습니다.
- 주소가 `.pdf` 로 끝나지 않으면(예: `download.do?id=…`) 경고만 합니다. PDF 파일을 바로 내려주는 주소인지 확인하세요.
- 그 서버가 CORS를 허용하지 않으면 사이트의 PDF 뷰어에서 열리지 않을 수 있습니다.

**확인** — `npm run data` 를 실행합니다. 문제가 있으면 `[data/competition.csv 12행] '모집인원' 값 '다섯' 은(는) 정수가 아닙니다.` 처럼
파일·줄 번호와 함께 모든 오류를 보여 주고, `public/data` 는 건드리지 않은 채 끝납니다(종료 코드 1 → 배포도 중단됨).

검사 항목: 필수 열 · 알 수 없는 대학ID · 지역/설립구분/전형유형/분류 값 · 정수가 아닌 인원 · 음수 · 학년도·날짜 형식 · URL 형식 · 중복 행 ·
전형명별 전형유형 일관성 · 참조한 PDF가 `public/` 에 대소문자까지 똑같은 이름으로 있는지 · PDF 경로에 `#` `?` `%`·제어 문자가 없는지 ·
외부 PDF는 `https://` 인지 · 큰따옴표 짝(닫는 따옴표 뒤의 글자 · 닫히지 않은 따옴표 · 요약·부제가 아닌 열의 줄바꿈, 위 '큰따옴표 짝 검사' 참고).

- universities.csv 의 한 행이 오류(예: 지역 `서울시`)이면 그 대학은 목록에서 빠집니다. 이때 다른 파일에서 그 대학ID를 쓰는 행마다
  '알 수 없는 대학ID' 오류를 내지 않고, 파일마다 `대학ID 3 의 361행은 대학ID 검사를 건너뛰었습니다 — universities.csv 4행의 오류를 먼저 고치세요.`
  라는 경고 한 줄만 보여 줍니다. universities.csv 자체를 읽지 못했을 때(따옴표 오류·필수 열 없음 등)도 다른 파일은 대학ID 검사를 건너뛰고
  파일마다 경고 한 줄만 보여 줍니다. 오류 목록은 최대 100건까지 출력합니다.

**Excel 사용 시** — "CSV UTF-8(쉼표로 분리)(*.csv)" 형식으로 저장하세요. 일반 "CSV" 로 저장하면 EUC-KR 이 되는데, 이 경우에도 읽기는 하지만 경고를 출력합니다.
내용만 지운 행은 Excel 이 `,,,,,,` 처럼 쉼표만 있는 행으로 저장합니다. 이런 행은 빈 행으로 보고 건너뛰며, 파일마다 몇 개를 건너뛰었는지 경고로 알려 줍니다.

## hasData 와 hasDetail

`public/data/universities.json` 의 각 대학에는 두 값이 붙습니다.

| 값 | 뜻 | 사이트에서 쓰는 곳 |
|---|---|---|
| `hasData` | competition.csv 에 그 대학의 경쟁률 행이 있음 | '경쟁률 제공' 배지, 경쟁률 추세, 학과 검색 |
| `hasDetail` | `public/data/univ/{대학ID}.json` 이 있음 = 경쟁률·모집요강·자료실·소식 중 하나라도 있음 | 대학 상세 탭(대학정보·모집요강·지난 경쟁률·자료실·소식)이 이 파일을 불러옴 |

모집요강 PDF는 경쟁률 발표보다 몇 달 먼저 나오므로, 모집요강만 올린 대학은 `hasData: false` · `hasDetail: true` 가 됩니다.
이 대학의 모집요강·자료실·소식 탭은 정상적으로 보이고, 대학정보·지난 경쟁률 탭은 '경쟁률 자료가 없다'고 안내합니다.

## 샘플 데이터 다시 만들기 (개발용)

```bash
npm run data:sample   # scripts/generate-sample-data.mjs → competition/guidelines/resources/news.csv
npm run data:pdf      # scripts/generate-sample-pdfs.mjs → public/files/univ/{id}/*.pdf
npm run data          # 검사 후 public/data/*.json 생성
```

- `data:sample` 은 시드 고정 난수를 쓰므로 몇 번 실행해도 같은 CSV가 나옵니다. 모집단위·전형 설정은 `scripts/sample-profiles.mjs` 에 있습니다.
  샘플 대상이 아닌 대학의 행이 CSV에 있으면(실제 데이터를 넣기 시작했다면) 덮어쓰지 않고 멈춥니다. 강제로 덮어쓰려면 `npm run data:sample -- --force`.
- `data:pdf` 는 **Playwright(Chromium)** 가 필요합니다. 프로젝트 의존성에는 넣지 않았으므로 전역 설치를 사용합니다.
  ```bash
  npm i -g playwright && npx playwright install chromium   # 처음 한 번
  npm run data:pdf                   # guidelines.csv·resources.csv 에 적힌 PDF를 모두 다시 생성
  npm run data:pdf -- --missing      # 없는 파일만 생성(직접 넣은 실제 PDF는 건드리지 않음)
  npm run data:pdf -- --only=3,5     # 특정 대학ID만
  ```
  전역 모듈을 찾지 못하면 `NODE_PATH=$(npm root -g) npm run data:pdf` 로 실행하세요.
  글꼴은 Gothic A1(OFL, google/fonts 저장소의 정적 TTF)을 내려받아 쓰고, 실패하면 Noto Sans KR(Google Fonts) → Pretendard(jsDelivr) → 시스템 한글 글꼴 순서로 대신합니다.
  모든 쪽에 "샘플 · 실제 대학 자료가 아님" 표시가 들어가며, 파일당 300KB를 넘으면 경고합니다.
- GitHub Actions 배포에서는 `data:sample`·`data:pdf` 를 실행하지 않습니다. 커밋된 CSV·PDF로 `npm run build`(→ `prebuild` 로 `build-data`)만 실행되며, Node 20 이상이면 추가 패키지가 필요 없습니다.
